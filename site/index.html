Metacheck

An Automated Tool to Check for Best Practices in Scientific Articles

Metacheck screens scientific manuscripts to identify potential issues or areas for improvement and guide researchers in adopting best practices. It is a module based open source tool. For information on the available modules, see the manual. Upload a paper or a folder below and you will receive a report with automated checks within minutes. Everything runs on SURF Research Cloud in the Netherlands, with an open source language model. This tool is GDPR compliant.Everything runs on your own computer, in the Metacheck Docker installation, also the conversion of PDFs (by GROBID), except the conversion of PDFs: a PDF is sent to the GDPR compliant GROBID server of Eindhoven University of Technology. The power check uses the language model in Ollama on your computer. The power check sends the paragraphs about statistical power to Mistral (EU), with your own API key.

Run Metacheck on a Repository

Choose a folder with data and code, or paste a link to an online repository, and receive a report that checks for FAIR principles.

Drop a folder or a .zip file here

Your browser packs the folder into a .zip before uploading it, at most 500 MB (1000 MB unpacked).

For a link, the server fetches the public files itself (GitHub, OSF, Zenodo, Dataverse, Dryad, ...): files over 100 MB are skipped, and at most 500 MB is fetched.

More checks

ResearchBox Check: the data and code in a ResearchBox. TU/e Data Manager Check: a data package against TU/e's archiving guidelines, as TU/e's data managers check it. Metacheck app: the paper report app, with the optional LLM power check.

What happens to your files

Uploaded files are deleted as soon as they have been read. Reports are kept for one hour. A report can only be fetched with its random job number, which only your browser knows. Nothing is sent to external services, the tool is fully GDPR compliant. One exception: when the PDF converter on SURF Research Cloud (bibr) does not answer, a PDF is converted by the GROBID server of Eindhoven University of Technology instead, and the report says so.

Uploaded files go to the Docker container on your computer, are deleted as soon as they have been read, and the reports are kept in the container for one hour. A PDF is converted by the GDPR compliant GROBID server of Eindhoven University of Technology, so it is sent there. The power check sends the paragraphs about statistical power to Mistral (EU), with your own API key. Checks that contact online services (Crossref, PubPeer, OSF, GitHub, ...) send only what they need to look up, such as DOIs, the reference list or repository links, and only when you choose those checks.

Use it from your own code

Every tool on this page is also a web interface you can call from R, Python, PowerShell or the command line, for example:

curl -F file=@paper.pdf https://this-server/api/report -o report.html

See the interactive documentation and the examples.
