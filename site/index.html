Metacheck

An Automated Tool to Check for Best Practices in Scientific Articles

Metacheck screens scientific manuscripts to identify potential issues or areas for improvement and guide researchers in adopting best practices. It is a module based open source tool. For information on the available modules, see the manual. Upload a paper or a folder below and you will receive a report with automated checks within minutes. Everything runs on SURF Research Cloud in the Netherlands, with an open source language model. This tool is GDPR compliant.

Checks

The default checks need no other service and are quick. The others contact services such as Crossref, PubPeer, the Retraction Watch database, OSF or GitHub, and can take several minutes.

Run Metacheck on a Repository

Choose a folder with data and code, or paste a link to an online repository, and receive a report that checks for FAIR principles.

Drop a folder or a .zip file here

Your browser packs the folder into a .zip before uploading it, at most 500 MB (1000 MB unpacked).

For a link, the server fetches the public files itself (GitHub, OSF, Zenodo, Dataverse, Dryad, ...): files over 100 MB are skipped, and at most 500 MB is fetched.

More checks

PsyArXiv Check: paste a PsyArXiv link and get a checklist of what to fix and to improve in the preprint. ResearchBox Check: the data and code in a ResearchBox. TU/e Data Manager Check: a data package against TU/e's archiving guidelines, as TU/e's data managers check it.

What happens to your files

Uploaded files are deleted as soon as they have been read. Reports are kept for one hour. A report can only be fetched with its random job number, which only your browser knows. Nothing is sent to external services, the tool is fully GDPR compliant.

Use it from your own code

Every tool on this page is also a web interface you can call from R, Python, PowerShell or the command line, for example:

curl -F file=@paper.pdf https://this-server/api/report -o report.html

See the interactive documentation and the examples.

Metacheck and bibr are open source software by scienceverse. Report problems on GitHub.
