Metacheck

ResearchBox Check: the data and code in a box, checked for reuse

Paste the link to a box on ResearchBox and receive a checklist of what to fix and what to improve in its data and code: whether the files can be found and opened, whether the code loads files that are in the box, uses absolute paths or records its package versions, and whether the data columns are described in a codebook. The R and Python code can also be run, in a closed sandbox. Everything runs on SURF Research Cloud in the Netherlands.The R and Python code can also be run, inside the Docker container. Everything runs on your own computer, in the Metacheck Docker image.

Check a ResearchBox

Paste the link to the box, or its number.

For example https://researchbox.org/1150. The server fetches the box's public files itself: files over 100 MB are skipped, and at most 500 MB is fetched.

What happens

The server fetches the box's public files from ResearchBox, checks them, and keeps the report for one hour. A report can only be fetched with its random job number, which only your browser knows. Other checks: papers and repositories, the TU/e data manager check.

Built on Metacheck, open source software by scienceverse.
