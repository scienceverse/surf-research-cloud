Metacheck

TU/e Data Manager Check: a data package against TU/e's archiving guidelines

This website is made for TU/e data managers to easily compare a data and code package against the archiving guidelines for RAPS (Research Archival Package Solution). Upload a paper or a folder below and you will receive a report with automated checks within minutes. Everything runs on SURF Research Cloud in the Netherlands, and relies on an open source language model to generate an adjusted README. This tool is GDPR compliant.

Check a Data Package

Choose the package folder, or paste a link to an online repository, and receive a report that checks it against TU/e's archiving guidelines.

Drop a folder or a .zip file here

Your browser packs the folder into a .zip before uploading it, at most 500 MB (1000 MB unpacked). Hidden files such as .DS_Store are sent too, because the check looks for them.

For a link, the server fetches the public files itself (GitHub, OSF, Zenodo, Dataverse, Dryad, ...): files over 100 MB are skipped, and at most 500 MB is fetched.

What happens to your files

The package goes to the metacheck server on SURF Research Cloud and nowhere else, with one exception: to decide whether people took part, up to 3 of the package's scientific documents (such as the manuscript) may be converted to text by TU/e's GROBID server. The uploaded package is deleted as soon as the check has read it, and the report is kept for one hour. A report can only be fetched with its random job number, which only your browser knows.

About the check

The checks follow TU/e's archiving guidelines in Research Cockpit and the RDLC document "Using Metacheck for data package review and paper analysis". Every decision behind them is described in the tue_datamanager_check repository, where you can also run the check on your own computer.

tue_datamanager_check is a module for Metacheck, open source software by scienceverse.
